# 本地 AI 图片编辑

[English](README.md) · [API 文档](docs/API.md)

图片应用位于 `apps/image`，与 `apps/audio` 音频应用分别启动。共享基础 UI 位于 `packages/ui`。独立管理模型与推理，不连接外部 ComfyUI 服务。

```powershell
# 在仓库根目录执行；首次安装图片应用共用的隔离运行环境
powershell -ExecutionPolicy Bypass -File apps/image/scripts/setup.ps1
npm install
npm run image:tauri -- dev
```

首次使用时，在设置中选择模型目录，或分别选择 Qwen Image 2.1 主模型、VAE 和 Qwen3-VL 8B 编码器文件，然后保存配置。支持选择不同目录中的文件，不预填个人模型路径；已有配置继续保留。现有两个 PE 提示词增强模型暂未启用。安装脚本只下载运行依赖，不复制／下载模型权重，不修改音频运行环境。

界面采用画布、工具栏、图层面板布局。支持图层移动、缩放、显示／隐藏、锁定、透明度、排序、复制、重命名、撤销／重做。勾选且可见的图层按照从底到顶的顺序，携带位置、缩放和透明度分别发送给模型。遮罩编辑以第一个参考图层为底图，请用单个底图图层执行局部编辑。

支持文生图、继续创作、透明 PNG、主体提取、全景、人物／产品保真、涂抹、圈选、独立遮罩、透明图及多图编辑。白色遮罩表示修改，黑色表示保留；生成后会将遮罩外内容从底图合成回来。全景接缝和人物保真效果取决于模型，不能保证像素级一致。透明度使用模型的 RGBA 输出。

工程使用 `.laimage` 格式，包含原始图片、图层状态、遮罩、提示词和参数，可重新导入二次编辑；不是 PSD。编辑停顿约 1.5 秒及正常关闭窗口前会自动保存；下次启动恢复上次内容。“最近记录”保留最近 30 条完整快照，点击即可恢复图层、遮罩、提示词和参数。相同图片共用存储，超过 30 条后淘汰最早记录。强制结束进程或断电可能丢失尚未保存的改动，长期保存仍可导出工程。生成记录独立持久保存，可下载 PNG 或作为新图层继续编辑。图片内嵌实际提示词及生成参数。

服务默认 `127.0.0.1:19877`，与音频服务端口和数据隔离。启动不加载模型；单队列执行，任务结束退出推理进程并释放显存。取消任务会终止当前推理进程。

详细边界、依赖许可与验证说明见英文文档。图片应用首版界面为中文；音频应用的三语支持保留。
