# 音乐创作预设

音乐生成页展开“创作预设与风格”，可选择创作目标、音色偏好、BPM 与目标分钟数。“应用创作预设”只填入参数，不自动提交任务；风格按钮可一键替换音乐风格输入。提示词使用英文音乐术语，界面提供中英日翻译。

## 预设与实际效果

| 目标 | 实际处理 |
| --- | --- |
| 优化伴奏 | 使用参考旋律/和弦重新编曲，添加清晰配器、低频控制、动态等提示，不是对原文件无损修复 |
| 同 BPM 伴奏 | 用户填写原 BPM，将数值写入提示词；目前不自动检测或强制锁定 BPM |
| 扩展构思为完整歌曲 | 提示生成前奏、对比段落、变化、桥段和结尾；目标分钟数乘以 60 后写入请求 `max_duration`。这是上限，不保证精确时长或无缝续接原文件 |
| 参考曲风重新生成 | 选择或描述目标曲风，并使用参考旋律/和弦重新创作；不自动识别上传文件的曲风 |
| 男声 / 女声版本 | 提示重新演唱的声线，整曲重生成，伴奏也可能变化；不等同于只替换人声的音色转换 |
| 纯音乐 BGM | 将歌词设为 `[Instrumental]` 并添加无人声提示。YuE2 没有硬性禁唱开关，结果需试听 |

纯音乐预设会替换当前歌词；当前页面会暂存原歌词，随后应用男/女声预设时可恢复。如果没有原歌词，请填写要演唱的内容。无歌词时优先按纯音乐处理。

省略、留空或只填写空白的 `lyrics` 会转换为 `[Instrumental]`，并补充无人声提示。`style` 可以省略或留空，无论是否有参考都不会随机补入曲风，也不会强制继承来源歌曲风格。已填写歌词时，空风格原样传入模型；歌词也为空时，只添加无人声提示，不指定曲风。任务记录保存实际输入，便于复用。

预设库统一存储在 `server/music_styles.json`，供前端风格按钮使用。预设为本项目编写的组合提示，不是官方模型参数，也不保证生成质量。

来源歌曲的“复用参数”等操作仍会主动回填其已保存风格；用户可以清空它，让模型自由发挥。当前没有曲风自动识别模型，留空不代表保证还原原曲风格。

## 风格资料来源

以下资料用于整理乐器、节奏和音色描述，不代表这些来源提供了本应用的提示词或认可生成效果：

- [中国乐器介绍](https://www.china.org.cn/olympics/kms/2008-08/08/content_16165432.htm)：参考古筝、笛子、二胡等配器描述。
- [WJEC Rock and Pop 教学资料](https://resource.download.wjec.co.uk/vtc/2020-21/el20-21_8-32/eng/aos-b-knowledge-organiser.pdf)：参考摇滚与流行的配器、节奏和结构。
- [Ableton：Tempo and genre](https://learningmusic.ableton.com/make-beats/tempo-and-genre.html)：速度是曲风特征之一，不存在所有风格共用的单一 BPM。
- [Ableton：Ambient](https://www.ableton.com/en/blog/collections/ambient/)：参考氛围音乐的持续音与声音空间描述。

Q版古风、动漫流行、电影配乐等为便于创作的场景组合，不是严格的音乐分类。
