# 界面语言

默认跟随 Windows 当前用户的显示语言：中文系统使用简体中文，日语系统使用日语，其他系统回退英文。浏览器预览使用浏览器语言（包括 ja-JP）。

在“应用设置 → 界面语言”选择“跟随系统 / 简体中文 / English / 日本語”。偏好保存在本机 WebView 的 localStorage 中，切换立即生效，重开应用仍保留。窗口重新获得焦点时会重新读取系统语言；手动选定语言不受系统变更影响。

界面语言独立于 TTS 的语言、歌词、歌名和用户提示词；切换不清空输入、不修改任务请求、模型配置或正在运行的任务。原始模型日志和未识别的底层报错保留原文，避免改变诊断信息。

翻译资源位于 `src/locales/zh-CN.json`、`src/locales/en.json` 与 `src/locales/ja.json`，使用中文源文本作为稳定键，动态信息用 `{0}`、`{1}` 占位。React 渲染时通过 `t` 查表，不依赖在线翻译、不修改 DOM 文本。日期显示使用当前界面语言。

运行 `node scripts/check-i18n.mjs` 检查三种语言的键、非空翻译及占位符一致性。
