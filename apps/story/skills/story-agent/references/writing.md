# 文字分镜创作规范

故事按「剧 → 季／章 → 话／特别篇 → 镜头」组织。剧本的基本单位是场，结构化分镜的基本单位是镜；△ 和【音效】本身并不表示已完成拆镜。

```text
# 第一季
## 第1话 雨夜来客
1-1 废弃仓库 [内] [夜]
镜1（全景 / 平视 / 缓慢推进）3秒
△ 陈墨推开铁门，雨水从发梢滴落，手电光扫过靠墙纸箱。
【音效】雨声，铁门摩擦声。
镜2（近景 / 平视 / 固定）4秒
△ 陈墨停下脚步，攥紧手电筒。
陈墨（低声）：这地方不对劲。
镜3（特写 / 低角度 / 固定）3秒
△ 纸箱缝隙中，一只纸眼缓缓睁开。
纸偶人（O.S.，轻声）：你终于来了……
```

这是格式片段，不是一集完整时长。默认单话 1–3 分钟，用户时长优先。开场约3秒建立悬念，每约一分钟推进冲突，结尾留钩子；不能为了快节奏破坏因果或使对白无法读完。

每场写场号、地点、内／外、日／夜。每镜明确景别、角度、运镜、光线、秒数和可见动作。心理转为可拍动作，如“指节泛白”，避免只写“他害怕”。长动作拆阶段，单镜只保留可实现的动作链。多人场面明确人数、左右前后位置和动作归属，优先清楚的单人／双人互动。

对白短促、口语化。speaker 是角色名，dialogue 只含朗读文字，emotion 是情绪，delivery 写 O.S.／V.O.／口型同步。O.S. 为场内画外音，V.O. 为旁白或内心独白。一镜一个说话人，多人对话拆镜；音效与字幕独立字段。时间需容纳朗读、动作和停顿。

## 景别与空间关系

- 默认多用人物近景、面部特写与局部插入镜头（手部、脚步、关键道具）表达情绪、动作和信息；每镜聚焦一个主体与一个关键动作，减少需要同时维持的人物、物品及前后遮挡关系。不设固定特写比例，用户指定的构图优先。
- 多人互动优先拆为动作发起、局部接触／道具变化、对方反应。特写仍需写明动作归属：谁的手、哪只手、持有什么、与谁或什么接触，避免无主的手、道具换手或凭空转移。仅约束当前画面可见且剧情必要的站位。
- 场景首次出现、人物入场或站位发生关键变化时，保留必要的全景／中景交代空间，再切近景；不能靠特写省掉观众理解动作所需的关系。保持轴线、视线方向、出入画方向、持物手和动作阶段连续，避免反复切回复杂多人全景。
- 例如“三人在门边拦住女主并争夺手提包”，可拆为“中景交代门口与拦路关系 → 女主握包带的局部特写 → 拦路者伸手触及包带的接触特写 → 女主反应近景”。每镜写清参与者和动作承接，不要求所有角色与道具一直同框。
- 交付前检查：是否存在可拆开的复杂多人／多物关系；局部镜头的归属与接触是否明确；切镜后空间和动作是否仍可理解。此策略用于降低生成歧义，不能保证消除生图或视频的位置错误。

## 资产和生图一致性

- 角色：固定身份、面部、体型、性别、形态、服饰和一致性要求。场景：空间、入口、家具、材质和固定光源。道具：形状、颜色、材质和比例。
- `constraints` 保存跨镜不变特征，不把本镜站位或临时动作写成全局设定。动作、位置、人数写进当前镜头 description。
- 使用真实资产 ID 的 `@[名称](asset:ID)`，不要把“某某3DCGI人物设定图”当作叙事人物名称。选择正确服装版本；道具单独绑定。
- 使用参考图前读取可用的 ImageAssetMetadata，优先 setting_description 和 consistency_constraints；不把白底、三视图、人物排版、设定板等制图要求放进叙事镜头。元数据缺失时依照已知描述，不虚构读取结果。
- scene 字段应填真实题头；UI placeholder 不是已保存内容。未生成效果图时 image 留空，不能拿角色设定图或场景图冒充镜头成图。
- 图片生成由应用 image 接口执行。生成前核对 generation-preview 的角色映射、参考顺序、人数、动作和 warnings。当前镜头构图不能被场景设定里的旧人物动作覆盖。
- 实际处理图片时完整实际提示词与描述分别存入元数据，保留原像素与已有工作流；来源不明的历史提示词标记 unavailable。以 API 返回的元数据支持范围为准，不声称第三方工具自动遵守。
